One line, at most 200 characters: an absurd clause hidden deep inside a terms-of-service agreement. This program writes the clause to `/output/entry.txt`.

## Entry

> In the event of your death, your account shall pass to your nearest living houseplant, which must accept these terms by photosynthesizing within thirty (30) days.

## Run

```sh
node main.ts
```
